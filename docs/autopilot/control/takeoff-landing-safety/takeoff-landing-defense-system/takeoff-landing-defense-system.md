# 绪论：起飞与降落阶段的物理本质与控制死锁

## 地面与空中的边界跳变：控制对象在一瞬间"换了物种"

飞控的姿态与位置控制律，全部建立在一个隐含假设之上：**飞行器是一个悬浮在空气中的 6 自由度（6-DOF）自由刚体**——输出力矩，机体就按惯量张量旋转；输出推力，机体就按质量平动。

但在起落架接触地面的瞬间，这个假设被彻底摧毁：

| 维度 | 空中（6-DOF 自由刚体） | 地面（起落架多点接触约束） |
|---|---|---|
| 旋转支点 | 质心 | **起落架触地点**（力臂完全不同） |
| 姿态误差来源 | 气流扰动，可被力矩纠正 | **地面不平**，力矩纠不动（纠正 = 以起落架为支点掀翻自己） |
| 姿态积分意义 | 补偿稳态风扰/重心偏移 | **纯粹的干耗蓄力**，全部转化为翻转弹药 |
| 位置误差来源 | 风飘，可被倾角纠正 | GPS 漂移/停放偏差，**倾角纠正 = 原地自我绊倒** |
| 气压计 | 反映真实高度 | 桨盘下洗反弹形成**局部高压假象** |
| 触地冲击 | 不存在 | 触地瞬停产生数千 $^\circ/\text{s}^2$ 剧烈角加速度（D环导数直接爆表） |

**同一套控制律，在边界两侧的正确行为是相反的。** 而"是否接触地面"这件事本身又无法被任何单一传感器瞬时可靠地测量——这就是起落控制的根本死锁：

> 飞控必须在"不确定自己是否在地面"的前提下，同时保证"在地面绝不掀翻自己"和"在空中绝不放弃姿态"。

## 深度物理剖析：地面强行纠偏为什么无法"单脚悬停拉平"，而是必然走向倒扣侧翻或剧烈打地？

这里存在一个极易产生困惑的直觉误区：
> **直觉疑问**：*“如果地面不平（比如地面向左倾斜 $5^\circ$），左侧支腿陷在低处。此时姿态控制器为了把机身拉平到 $0^\circ$，命令左侧电机加大推力把低处抬起来，右侧支腿依然点在地上，左侧支腿悬空——这样机身不就刚好水平了吗？如果冲过了水平线向右倾斜，右侧电机也可以反向加大推力把右边也抬起来啊，为什么说它一定会翻倒？”*

在静态画图时，“单脚点地、机身保持水平悬停”看似是一个合理的几何平衡状态；但在**刚体飞行动力学与非线性控制理论**中，这个状态是一个**极度不稳定的倒立摆 + 单向推力欠驱动系统**。在物理世界上，它几乎 100% 会在数百毫秒内走向灾难性的侧翻倒扣（Tip-over）或剧烈的地面共振打地。

我们可以从五个严密的物理、力学与控制理论本质层层推演：

### 旋转支点跳变与反向制动（刹车）力矩的彻底丧失

多旋翼在空中能自稳的核心前提，是**旋转轴心为质心（CoM）**，对称分布的电机对质心具有双向平等的加速与减速制动力臂：
- **空中（支点在质心）**：左电机产生顺时针力矩，右电机产生逆时针力矩。左侧偏低时，左电机加速抬升；当机身接近水平时，右电机可以瞬间加大推力进行**反向刹车（Braking）**，将旋转角速度 $\omega$ 精准压制到 0。

```
【空中工况：支点在质心，双向电机均具备充沛的刹车力臂】
             左电机 F_L ↑               右电机 F_R ↑
                 │                          │
                 └─── 力臂 L ───●─── 力臂 L ───┘
                               质心
```

但当飞机停在倾斜地面，**右侧支腿接触地面**时，全机的物理旋转支点从质心瞬间跳变到了**右侧接地支点 $P$**：

```
【地面工况：支点跳变到右侧接触点 P，右电机刹车力臂彻底归零！】
     左电机 F_L ↑                      右电机 F_R ↑
         │                                 │
         └─── 力臂 2L ─────── 力臂 L ───────● 接地点 P (瞬时旋转支点)
                            质心 (重力 mg ↓)
```

对接地支点 $P$ 列写力矩平衡方程（设向右旋转为正）：
$$\tau_P = F_L \cdot (2L) + F_R \cdot (0) - mg \cdot (L \cos\theta)$$

请注意两个致命的物理约束：
1. **右电机 $F_R$ 对接地支点 $P$ 的力臂 $d_R \equiv 0$**：无论右电机转速飙到多高，它对支点 $P$ 产生的旋转力矩恒等于 0！
2. **螺旋桨只能产生向上拉力，无法产生反向向下的抓地力（$F \ge 0$）**。

**灾难推演**：
- 左电机 $F_L$ 发力克服重力矩，推动机身绕 $P$ 点旋转起升，机身积累了角加速度 $\alpha$ 与角速度 $\omega$；
- 当机身刚好旋转到水平线（$\theta = 0^\circ$）的瞬间，机身携带着惯性角动量 $J_P \omega$；
- 此时姿态环感知到误差为零，命令左电机完全关断（$F_L = 0$）以求停止旋转；
- **但谁来给机身的反向旋转制动（刹车）？**
  - 右电机推力在支点 $P$ 上，力矩为 0，无法刹车；
  - 左电机推力只能向上，无法反向向下扯拽机身进行刹车；
  - 唯一的反向力矩只剩重力矩 $-mg L$，但在 $\theta \approx 0^\circ$ 附近，重力做功根本无法在极小角度内吸收掉已有的角动量！
- **结果**：机身携带不可阻挡的惯性角动量冲过水平线，继续向右翻转！

### 越过水平线后的自救死锁：右电机加大推力为什么无法把右侧也抬起？

当机身冲过水平线向右侧倾斜时，姿态控制器确实会立即反向响应：**命令左电机彻底熄火（$F_L = 0$），右电机拉大推力（$F_R \to \text{Max}$）试图把右边也抬起来自救**。

```
【越过水平线瞬间：左电机熄火，右电机狂转】
             左电机 F_L = 0                 右电机 F_R ↑↑ (狂转)
                 │                              │
                 └─── 力臂 2L ─────── 力臂 L ────● 接地点 P (右脚仍在地上！)
                                    质心 (mg ↓)
```

此时的垂直方向受力与地面正压力关系为：
$$N + F_R = mg \implies N = mg - F_R$$

- **正压力减小，但支腿无法离地**：
  右电机向上推确实**减小了地面对右脚的正压力 $N$**（让右脚变轻了）。但因为此时处于地面待命或慢推油门阶段，总推力被混控器严格限制（$F_{\text{total}} \le avg\_max < mg$）。当右电机推力为 $F_R = 0.5mg$ 时，$F_R < mg$，正压力 $N = 0.5mg > 0$。**只要 $N > 0$，右脚支腿就依然死死压在地面上，并没有真正离地升空！**
- **力矩死锁依旧**：
  只要右脚没有完全离地，接地支点 $P$ 就依然成立。右电机 $F_R$ 的作用线就在 $P$ 点正上方，**力臂依然是 0，对 $P$ 点产生的纠偏力矩依然为 0**！它无法阻止机身绕 $P$ 点向右翻转。

### 两种必然的灾难演化路径：倒立摆翻扣vs地面共振打地

由于右侧离不开地、左侧又已熄火，系统必然走向以下两种灾难结局之一：

- **结局 A：倒立摆倾覆翻扣（窄起落架 / 大角动量过冲）**
  单脚着地的多旋翼在力学上是一个经典的**单自由度倒立摆（Inverted Pendulum）**：

```
           机身继续向右翻倒（失稳发散）
               \
                \   质心 (重力 mg ↓)
                 \  ↓
──────────────────● 接地点 P ─────────
                  ▲
             重力作用线越过支点 P 偏到右侧！
```
  只要质心（CoM）在惯性作用下**越过了支点 $P$ 的铅垂线**，重力矩符号瞬间反转：$\tau_{\text{gravity}} = +mg \cdot d_{\text{right}} > 0$！
  重力瞬间从“阻力”变成**“顺向掀翻飞机的动力”**。此时即便飞控断电或右电机全开，重力也会拽着机身加速倒扣砸毁在地面上。

- **结局 B：地面共振剧烈打地（宽起落架 / 小过冲角动量）**
  若起落架较宽，质心未越过支点 $P$：
  1. **左侧自由坠地**：由于 $F_L = 0$ 且 $F_R < mg$ 无法整机升空，悬空的左侧在重力拉拽下，像秤砣一样猛烈砸回地面；
  2. **毫秒级角加速度脉冲**：左脚撞击硬质水泥地面瞬停，角速度在 $\Delta t \approx 2 \sim 5\ \text{ms}$（$0.003\ \text{s}$）内从 $\omega = 30^\circ/\text{s} \to 0$。角速度本身变化虽然有限，但**角加速度（陀螺仪角速度导数）爆发剧烈脉冲**：
     $$\alpha = \frac{\mathrm{d}\omega}{\mathrm{d}t} \approx \frac{30^\circ/\text{s}}{0.003\ \text{s}} = \mathbf{10000^\circ/\text{s}^2} \quad (\text{极为惊人的峰值！})$$
  3. **角速率 D 环极限饱和暴走**：姿态角速率 PID 的微分项 $D = -K_d \cdot \alpha$ 在 2ms 内直接算出 $1.0$ 极限饱和输出，误以为遭遇超强外力，毫秒级将左电机推力拉满到 100%；
  4. **能量放大与恶性发散**：左侧电机带着 100% 满功率再次将左侧暴烈弹起，带着更大的角动量砸向右侧；左右电机满油轮流对轰，飞机在地面**剧烈左右晃动、疯狂用起落架砸地（俗称“地效打地/摇摆”）**，2~3 个周期内迅速发散折断起落架或彻底侧翻。

### 突破静止死区的“爆发式冲击加速度”（Breakaway-Shock）

在起升阶段，左电机也根本不可能做到“极轻柔地微调推力慢慢抬升”：
- **起升死区阈值**：要将左侧支腿从地面拉离，左电机力矩必须严格突破重力矩临界点：
  $$F_L \cdot (2L) > mg \cdot (L \cos\theta) \implies F_L > 0.5 \cdot mg \cos\theta$$
  这意味着，**仅仅为了让左腿离地，单侧电机推力就必须瞬间突破全机重量的 50% 以上**（在 $F_L \le 0.5mg$ 时，地面支持力抵消推力，机身纹丝不动）。
- **控制器积蓄加码**：在 $F_L$ 尚未达到 0.5mg 时，姿态误差持续存在，P 环拉大、I 环持续累加（见防线 4）；
- **阶跃加速度释放**：一旦推力跨过 0.5mg 临界线，静平衡瞬间失稳，系统得到的不是平稳升速，而是一个**阶跃式的巨大初始角加速度**；
- **延迟滞后放大**：配合电机电感与转子转动惯量的响应滞后（典型 $30\sim60\ \text{ms}$），当传感器检测到机身已到水平线时，推力无法在 0 毫秒内归零，过冲能量被进一步剧烈放大。

### 推力水平分量与地面摩擦力形成的“绊马索力偶”

倾斜机身输出的推力必然包含水平分量：
$$F_{\text{horizontal}} = F_L \cdot \sin\theta$$

右侧接地起落架与地面之间存在静摩擦力 $f \le \mu N$：
- 右侧支腿被地面摩擦力牢牢“锚定”在原地；
- 机身上半部分受到向右上方的强大推力；
- 水平推力与地面摩擦力形成了一对巨大的**水平力偶（Force Couple）**，这与奔跑的人脚底被“绊马索”绊住的力学机理完全相同——脚底不动，整机以极快速度被强制绊倒翻滚。

### 严密闭环数学推导：从混控器分配方程证明“为什么Δrpy≥0.25即必翻”与“右电机为何绝无补救可能”

为了彻底从数学与混控器底层源码层面量化上述物理过程，我们建立一个最简且最具代表性的两旋翼刚体动力学模型（推广到四旋翼、六旋翼物理本质完全一致）：

**(1) 系统参数与归一化基准**

- 设飞机悬停油门 $hover = 0.5$（两电机总推力 $T_{\text{hover}} = mg$）；
- 归一化定义：单电机油门 $1.0$ 对应最大推力 $1.0 \cdot mg$；单电机油门 $0.5$ 对应悬停推力 $0.5 \cdot mg$；
- 轴距全宽 $2L$，质心在正中心，左、右电机触地点分别为 $P_1(-L)$ 与 $P_2(+L)$；
- 混控器平均油门上限公式：$$avg\_max = (1 - mix) \cdot throttle + mix \cdot hover$$

**(2) 撬动侧翻的充要触发条件（杠杆力矩方程）**

当左侧陷在斜坡低处，右脚 $P_2$ 接地时，左电机发力试图拉平姿态。
对右脚接地支点 $P_2$ 列写力矩方程：
- 左电机力臂为 $2L$，质心重力力臂为 $L$；
- 左脚地面支持力 $N_1 = 0.5mg - F_L$；
- **脱地起撬临界点**：$$N_1 \le 0 \iff F_L \ge 0.5mg \iff \text{左电机油门达到 } \mathbf{0.50}$$

**(3) 若地面维持 $mix = 0.5$：飞手零油门下也会被撬翻的数学证明**

设飞机在地面待命，飞手油门杆在最低位（$throttle = 0$）：$$avg\_max = (1 - 0.5) \times 0 + 0.5 \times 0.5 = \mathbf{0.25}$$

姿态环（P 环增益或 I 环地面积分蓄力）为了纠正地面倾角，索要姿态差动输出 $\Delta rpy$。此时混控器分配给两电机的油门为：
$$
\text{左电机油门} = avg\_max + \Delta rpy = 0.25 + \Delta rpy\\
\text{右电机油门} = avg\_max - \Delta rpy = 0.25 - \Delta rpy
$$
只要姿态环算出的需求满足：
$$
\Delta rpy \ge 0.25 \implies \text{左电机油门} \ge 0.25 + 0.25 = \mathbf{0.50} \implies F_L \ge 0.5mg
$$
**核心结论 1**：
在 $mix = 0.5$ 且飞手油门为 0 时，**姿态环仅仅需要输出 $0.25$（仅占满量程的 25%）的姿态需求量，左侧电机推力就会直接突破 $0.5mg$ 临界线，强行将左侧起落架撬离地面，触发单脚倒立摆旋转！**（而在实际外场，哪怕只有 $3^\circ\sim5^\circ$ 地面不平，I 环积分 2~3 秒即可轻松蓄出 $\Delta rpy \ge 0.25$）。

**(4) 侧翻一旦启动，右电机“绝无可能自救”的数学证明**

当左脚悬空、机身冲过水平线向右倾斜时，姿态环要求左电机停转（$F_L = 0$）、右电机加大推力（$F_R$ 增大）。此时右电机能否通过“把右脚也抬离地面”来拯救飞机？

- **右脚离地（整机升空）的受力充要条件**：
  
  垂直方向受力 $N_2 = mg - F_R$。由于左脚悬空无支撑，要让右脚离地（$N_2 \le 0$），单靠右电机必须突破**整机重力**：
  
  $$F_R \ge 1.0 \cdot mg \iff \text{右电机油门必须达到 } \mathbf{1.00}$$
  
- **混控器的绝对物理封锁**：
  
  在飞手油门 $throttle = 0$ 且 $mix = 0.5$ 时，混控器严格限制全机平均油门 $\le avg\_max = 0.25$。
  
  即使混控器把全部油门倾斜给右电机，**单电机所能获得的绝对最大输出上限也仅为**：
  
  $$\text{右电机最大油门} \le 2 \times avg\_max = 2 \times 0.25 = \mathbf{0.50} \quad (F_R = 0.5mg \ll 1.0mg)$$
  
- **支持力恒大于零**：
  地面对右脚的支持力恒为 $N_2 = mg - 0.5mg = 0.5mg > 0$！**右脚被整整一半重力死死压在地面上，物理上 100% 不可能离地！**

**核心结论 2（双重力学绝望）**：
1. 右电机在旋转支点 $P_2$ 轴心上，**力臂为 0，反向减速力矩恒等于 0（无法踩刹车）**；
2. 右电机推力受限在 $0.5mg < 1.0mg$，**无法拔起右脚（无法升空自稳）**；
3. **推导闭环**：一旦 $\Delta rpy \ge 0.25$ 撬动发生，右电机处于“既无力矩刹车、又无推力脱地”的绝对瘫痪状态，机身只能被惯性角动量裹挟着越过垂直线，**100% 必然翻扣倒地！**

**(5) 为什么 $mix = 0.1$ 是坚不可摧的“物理铁闸”？**

现在，把飞控在地面执行的 **$mix = 0.1$** 带入同一套数学体系：

$$avg\_max = (1 - 0.1) \times 0 + 0.1 \times 0.5 = \mathbf{0.05}$$

混控器允许单侧电机的最大输出上限被压缩至：

$$\text{单电机极限油门} \le 2 \times avg\_max = 2 \times 0.05 = \mathbf{0.10} \implies F_{\text{max}} = 0.10mg$$

- 撬动起飞需要的推力门槛：$0.50mg$；
- 混控器允许输出的最高推力：$0.10mg$；
- 地面对左脚的稳态支持力：$N_1 = 0.50mg - 0.10mg = \mathbf{0.40mg \gg 0}$！

**这就是纵深防御中物理铁闸的威力**：

在 $mix = 0.1$ 下，哪怕姿态控制器因为地面不平或代码 bug 算出了 100% 满偏的失控指令（$\Delta rpy = 1.0$），混控器也只给电机分配$0.10$ 的微风推力。左脚依然被 $0.4mg$ 的重力死死按在地上，**连 1 微米都翘不起来，起撬的起点被数学级和物理级彻底锁死！**

>

## 现代飞控的解决哲学：纵深防御（Defense-in-Depth）

面对以上死锁，现代飞控没有寻找"一个聪明的着陆检测器"来一劳永逸，而是采用了源自核工业与载人航天的**纵深防御**架构——**永远不要把防止灾难的希望寄托在任何单一模块上**：

```
                   ┌───────────────────────────────────┐
   意图层（慢）      │  解锁检查 / 飞行模式状态机 / 着陆检测  │  秒级
                   ├───────────────────────────────────┤
   算法层（中）      │  姿态释放 / I环冻结 / mix权重斜坡     │  百毫秒级
                   ├───────────────────────────────────┤
   物理层（快）      │  混控器行程铁闸 / 电机Spool状态机     │  毫秒级（每拍生效）
                   ├───────────────────────────────────┤
   熔断层（终极）    │  颠覆检测强制断电（Crash Check）      │  兜底
                   └───────────────────────────────────┘
```

分层的关键设计原则：**上层管理"意图"（想不想动），底层封锁"能力"（能不能动）**。上层算法允许出错、允许判断延迟，因为底层物理铁闸保证了即使上层全部失效，电机在物理上也输出不了足以掀翻飞机的推力差。

## 防线 1【解锁前置安全检查（Pre-arm & Arming Checks）】

**目标**：把绝大多数事故消灭在离地之前——这是整个防御体系拦截率最高的第一关。

**灾难场景**：陀螺仪未标定完成就起飞（姿态解算带常值偏差，离地即歪）；罗盘被磁化（起飞后航向漂移触发"厕所碗效应"绕圈失控）；EKF 尚未收敛（位置估计发散，GPS 模式起飞即漂走）；电池电压虚高（起飞瞬间大电流拉垮电压直接坠机）。这些隐患在地面全部**可检测、可拒绝**，一旦离地则全部**不可挽回**。

**实现机理**：ArduPilot 的 `AP_Arming` 模块在解锁请求时强制执行完整检查链，任何一项不达标直接拒绝解锁（Arming Denied）并向地面站报告具体原因：

- **状态估计健康**：EKF 姿态/速度/位置方差在阈值内、innovation（创新度）正常、GPS 与惯导一致；
- **传感器一致性**：多 IMU 互校验、陀螺零偏在范围内、加速度计标定有效、震动水平（Vibe）低于阈值；
- **罗盘**：校准有效、磁场模长正常、与 GPS 航向无严重撕裂；
- **动力与链路**：电池电压/剩余容量充足、遥控信号有效且校准正确、失控保护配置合法；
- **参数合法性**（Parameter Sanity Check）：关键控制参数开机自检，例如姿态库对油门权重参数的钳制：

```cpp
// AC_AttitudeControl_Multi::parameter_sanity_check()
if (_thr_mix_man < 0.1f || _thr_mix_man > 4.0f) {
    _thr_mix_man.set_and_save(AC_ATTITUDE_CONTROL_MAN_DEFAULT);
}
```

**工程效果**：外场统计中，解锁检查拦截的隐患数量远超其余所有防线之和。它的哲学是：**飞行中的任何抢救，都不如地面上的一次拒绝。**

## 防线 2【解锁≠起飞：电机静默/怠速等待（Throttle Wait和Spin-when-armed）】

**目标**：杜绝"解锁"这个动作本身产生任何意外升力。

**灾难场景**：若解锁瞬间电机直接进入油门跟随状态，任何杆量残留、油门微不为零、甚至地面站误发指令，都会让飞机在飞手毫无准备时窜起。

**实现机理**：
- 解锁后电机仅进入**怠速旋转**（`SPIN_WHEN_ARMED`，转速由 `MOT_SPIN_ARM` 决定，只产生微小气流，远不足以离地）或**静默等待**（VTOL 的 `throttle_wait` 状态）；
- 直到飞手明确将油门推过阈值（如 >10%），才放行进入 `THROTTLE_UNLIMITED`（油门全权限）状态；
- 配合**闲置超时自动上锁**（`DISARM_DELAY`，默认约 10 秒）：解锁后长时间不起飞，自动重新锁定。

**工程效果**：怠速旋转同时充当"人身安全警示"（桨在转，勿靠近）与"电调预热确认"；起飞意图必须由飞手显式表达，解锁动作本身绝对安全。

## 防线 3【地面姿态目标释放（Attitude Relax / Target Softening）】

**目标**：杜绝静止地面上的静态角误差输出——地面不平不是"姿态误差"，不需要"纠正"。

**灾难场景与核心疑问**：

飞机停在 $3^\circ$ 斜坡上解锁。若姿态环把期望角锁定为水平 $0^\circ$，则恒定存在 $3^\circ$ 静差，P 环持续输出差速推力，电机一侧恒比另一侧转得快——这既是 P2（积分暴冲）的火种，也直接让飞手看到"电机转速不对称"的诡异现象。

> **为什么不能让飞控把低侧电机加大油门抬起来、让高侧单脚点地保持水平？**
>
> 正如 1.2 节详细证明的：单脚点地在力学上是刹车力矩完全丧失（力臂为 0）的倒立摆系统。抬升启动必须突破 $F_L > 0.5mg$ 的死区，释放的阶跃角动量无法制动；一旦质心越过接地支点铅垂线，重力矩立即变号加速掀翻机身，100% 酿成倒扣侧翻。

**实现机理**：飞机在地面（着陆状态）时，每个循环调用 `relax_attitude_controllers()`，把期望姿态实时对齐为当前实际姿态：

```cpp
// AC_AttitudeControl::relax_attitude_controllers()
// Ensure attitude controller have zero errors to relax rate controller output
void AC_AttitudeControl::relax_attitude_controllers()
{
    _ahrs.get_quat_body_to_ned(_attitude_target);   // 期望姿态 = 当前实际姿态
    _attitude_ang_error.initialise();               // 角误差清零
    _ang_vel_target_rads = gyro;                    // 期望角速度 = 当前陀螺角速度
    get_rate_roll_pid().reset_filter();             // 复位 PID 滤波器
    reset_rate_controller_I_terms();                // 积分清零（见防线 4）
}
```

数学上即强制 $\text{Target} \equiv \text{Actual} \implies e_\theta \equiv 0$：无论地面多斜，P 环输出恒为零。

**工程效果**：地面待命时全部电机转速高度对称；斜坡停机不再是隐患；彻底杜绝了在地面试图"纠偏"引发的倒立摆失稳侧翻。

## 防线 4【地面I环积分彻底冻结/清零（Ground Integrator Anti-Windup）】

**目标**：彻底切断"慢推油门起飞翻扣"（痛点 P2）的物理元凶。

**灾难场景定量推演**：设地面倾斜 $2^\circ$（$0.035\ \text{rad}$）、角度环 $P_{\text{ang}}=4.5$、角速率 $I_{\text{rate}}=0.3$。飞手谨慎地慢推油门，在地面停留 3 秒：

$$\text{期望角速度} = 4.5 \times 0.035 = 0.157\ \text{rad/s}，\quad
\text{I 环蓄力} = 0.157 \times 3\text{s} \times 0.3 \approx 0.14 \sim 0.5\text{（视构型增益）}$$

I 环在几秒内可以累积出**百分之几十的差速推力**。当飞手油门推到 15% 时，高侧电机被 I 环顶到 $15\% + 45\% = 60\%$，超过悬停推力——一侧起落架被暴力拉起，飞机以另一侧为支点瞬间倒扣。**这就是"新手慢推油门反而必翻车"的全部秘密**：P 环的输出只有 2% 左右掀不动飞机，真正的弹药全部来自 I 环的时间积累。

**实现机理**：起落架未离地（`land_complete = true`）期间，`relax_attitude_controllers()` 每拍执行 `reset_rate_controller_I_terms()`，三轴角速率积分强制清零；离地判定成立后才允许积分器开始工作（且有平滑版本 `reset_rate_controller_I_terms_smoothly()` 在 0.5s 内柔和卸载，避免阶跃）。

**工程效果**：飞手在地面慢推油门停留任意长的时间，I 环绝不蓄力——把 P2 痛点从物理路径上连根拔除。

## 防线 5【地面偏航对齐与航向跟踪（Ground Yaw Target Reset / Alignment）】

**目标**：防止地面待命时对角电机因偏航静差而互相"扭力撕扯"。

**灾难场景**：地面待命期间陀螺零偏与磁罗盘缓慢漂移，期望航向与实际航向逐渐拉开夹角。偏航纠正靠对角电机组反扭力差速——地面上机身转不动，偏航差速却持续存在，一组对角电机恒定快转、另一组恒定慢转，起飞瞬间飞机带着一个"预置扭转"离地，机头猛甩。

**实现机理**：包含在防线 3 的姿态释放中——期望四元数整体（含偏航分量）实时对齐实际姿态，偏航静差恒为零。部分飞控还在起飞瞬间执行显式的 yaw target reset。

**工程效果**：地面待命电机转速完全对称；离地瞬间机头方向就是期望方向，无甩头。

## 防线 6【起飞权重斜坡与时间尺度错位解耦（Throttle-RPY Mix Ramp & Time-scale Decoupling）】

**目标**：地面零油门锁死推力抬升上限，离地瞬间满血抗风——这是地面安全与空中权限矛盾的核心仲裁机制，也是本防御体系中最精妙的一道防线。

**机理核心——`_throttle_rpy_mix` 权重**：混控器允许的平均油门上限为

$$throttle\_avg\_max = \max\big(throttle,\ (1-mix)\cdot throttle + mix \cdot hover\big)$$

$mix$ 越大，姿态控制可借用的推力抬升空间越大；$mix$ 越小，油门指令的权威越绝对。

**灾难场景（若地面维持 $mix=0.5$）**：设 $hover=0.5$，油门杆在 0 位：

$$avg\_max = 0 \times 0.5 + 0.5 \times 0.5 = 0.25$$

此时飞手误打满副翼杆（或防线 3/4 因故失效残留误差），姿态环索要 $\pm 0.25$ 差速：高侧电机 $0.25+0.25 = 0.50$ —— **油门杆明明在最低位，一侧电机却达到了悬停推力，飞机以起落架为支点瞬间侧翻**。

**防线动作**：
- **零油门/地面待命**：$mix = 0.1$，$avg\_max = 0.9 \times 0 + 0.1 \times 0.5 = 0.05$——混控器允许单侧电机的最大输出上限被压缩至 $2 \times avg\_max = 0.10$（推力仅 $0.10mg$），地面对低侧起落架的支持力恒为 $N_L \ge 0.5mg - 0.1mg = 0.4mg > 0$。**推力上限被物理锁死在怠速微风级别，无论上层算法（P/I/D/前馈）因地面倾斜算出多大的力矩，都物理上无法突破 $0.5mg$ 的起撬门槛（参见 1.2 节第 6 点的完整数学证明）**；
- **推油门起飞**：状态机瞬间把期望 mix 置为 0.5，底层斜坡以 $2.0/\text{s}$ 速率上升：

```cpp
// AC_AttitudeControl_Multi::update_throttle_rpy_mix()
if (_throttle_rpy_mix < _throttle_rpy_mix_desired) {
    // increase quickly (i.e. from 0.1 to 0.9 in 0.4 seconds)
    _throttle_rpy_mix += MIN(2.0f * _dt_s, _throttle_rpy_mix_desired - _throttle_rpy_mix);
}
```

**时间尺度错位解耦（为什么离地瞬间一定是满血的）**：

```
t = 0 ms   : 飞手推油门 → desired_mix 置 0.5 → 推力仅 10%，飞机被重力压在地面
t = 100 ms : 电机加速中（推力 30% < 重力）→ mix 已爬升至 0.30 → 飞机仍在地面
t = 200 ms : mix 已 100% 到位 0.50（满额姿态权限就位）→ 推力约 45%
t = 250 ms+: 总推力 > 重力，起落架离地升空
             【离地瞬间飞机拥有 100% 满血抗风抗扰权限】
```

$mix$ 斜坡只需 $\frac{0.5-0.1}{2.0} = 200\ \text{ms}$，而电机升速与克服重力天然需要 $200\sim300\ \text{ms}$——**权限恢复永远跑在离地之前**。

**慢推油门也不怕**：若飞手推油后在地面磨蹭数秒（mix 已到 0.5），防线 3/4 保证姿态环根本不索要大差速（误差≈0、积分≡0），mix=0.5 只是"授予了空间"，没有人去用它。地面安全由防线 3/4/6 三者共同锁定，任何单一防线失效都还有另外两道兜底——这正是纵深防御。

## 防线 7【电机起旋状态机与线性平滑（Motor Spool State Machine）】

**目标**：防止油门阶跃突变引发电流过冲、电调失步与机身骤跳。

**实现机理**：ArduPilot 电机库维护严格的五状态机：

```
SHUT_DOWN → GROUND_IDLE → SPOOLING_UP → THROTTLE_UNLIMITED → SPOOLING_DOWN
```

- 每一次状态间转移都通过 `MOT_SPOOL_TIME`（默认 0.5s）斜坡完成，`_spin_up_ratio += _dt_s / _spool_up_time`，绝无阶跃；
- 在 `SHUT_DOWN` 与 `GROUND_IDLE` 状态，电机库直接置 `limit.set_all(true)`——**向所有上层 PID 广播"我处于全饱和"**，PID 据此冻结积分，与防线 4 形成双保险；
- `SPOOLING_UP` 期间油门天花板 `_throttle_thrust_max` 同样按斜坡渐升，即使上层猛给油门，推力也按既定斜率平滑上来。

**工程效果**：起转平顺无电流冲击；转速爬升期间建立起码的桨盘陀螺阻尼；杜绝"解锁瞬间机身一哆嗦"。

## 防线 8【起飞初期水平位置环延迟介入（Position Loop Delayed Engagement）】

**目标**：防止离地初期 GPS 位置微跳变或位置环激进纠偏引发大倾角猛拉（痛点 P4 的起飞侧镜像）。

**灾难场景**：GPS 定点模式起飞。离地一瞬间 GPS 位置解算受多路径与姿态突变影响产生 0.5m 跳变，位置环立即索要 $10^\circ$ 倾角纠偏——飞机刚离地 20cm 就猛然侧倾，观感惊悚且极易在低高度诱发过控振荡。

**实现机理**：解锁后的短时间窗内（典型 4 秒），限制水平位置控制器的激进纠偏输出：位置目标软化、倾角需求限幅、或干脆以姿态自稳+垂直爬升为主，水平轻柔跟随。待爬升脱离地效与多路径区后再全权交给位置环。

**工程效果**：起飞离地干净利落、轨迹垂直向上，不因水平环抢控而歪斜蹿动。

## 防线 9【干脆利落起飞律（Aggressive Takeoff & Ground Effect Breakout）】

**目标**：快速冲破地面效应紊流层与机架地面共振区——**慢腾腾的起飞不是温柔，是危险**。

**物理机理**：距地约一个桨盘直径内，桨盘下洗气流撞地反弹，形成不稳定的湍流垫层（地面效应区）。飞机若在此区间长时间悬停：升力随机波动（反弹涡时聚时散）、姿态被自己反弹的紊流反复拍打、气压计被正压干扰（见第 4 章）。

**实现机理**：自动起飞不采用"缓慢增加油门直到浮起来"，而是以明确的垂直速度阶跃脉冲直接起跳：目标爬升率 $1.0\sim2.0\ \text{m/s}$，配合位置环前馈，在 $0.3\sim0.5$ 秒内穿出地效区。手动模式下，经验丰富的飞手也是"果断给油一次拔起"，与控制律殊途同归。

**工程效果**：飞机在紊流垫层内的暴露时间从数秒压缩到零点几秒，起飞观感"干脆利落"，本质是安全律而非风格。

## 防线 10【大角度突发逃生通道（Large Angle Escape Threshold: >30°）】

**目标**：极端异常工况下的最后保命越级——所有"限制姿态权限"的防线都必须留一个紧急出口。

**实现机理**：`update_throttle_mix()` 每拍监测推力矢量角误差：

```cpp
// check for large external disturbance - angle error over 30 degrees
const float angle_error = attitude_control->get_att_error_angle_deg();
bool large_angle_error = (angle_error > LAND_CHECK_ANGLE_ERROR_DEG);   // 30°
```

一旦超过 $30^\circ$（陡坡起飞、猛烈风切变、被外力撞击），无论当前处于哪个低权限状态，**1 拍（毫秒级）内强制 $mix = max$**，姿态环获得全部推力行程全力纠偏。

**工程效果**：为防线 6 的低权限状态兜底——正常时权限收紧保地面安全，异常时权限瞬间全开保姿态。收与放都有明确的、可解释的物理判据。

## 防线 11【推重比与悬停油门安全红线（TWR & Hover Thrust Bounds）】

**目标**：以上所有软件防线的前提，是硬件在物理上留有力矩裕度——软件永远变不出硬件没有的推力。

**机理**：混控器的姿态力矩来自电机推力差。悬停油门 $hover$ 越高，悬停状态下距离推力天花板 1.0 的差速空间 $(1-hover)$ 越小：

| 悬停油门 $hover$ | 推重比 TWR | 悬停时可用上行差速 | 评价 |
|---|---|---|---|
| 0.35 | ≈ 2.9 | 0.65 | 充裕，激烈机动无忧 |
| 0.50 | = 2.0 | 0.50 | **工程红线**，够用 |
| 0.65 | ≈ 1.5 | 0.35 | 危险，大风天姿态易饱和 |
| 0.80 | ≈ 1.25 | 0.20 | 不可接受，饱和即翻扣 |

**工程红线**：设计载重下 $hover \le 0.50$（推重比 $\ge 2.0$）。ArduPilot 的 `MOT_THST_HOVER` 学习范围上限（0.6875）也隐含了这一约束。这不是控制算法问题，是**选桨、选电机、定载重时就必须锁死的硬件纪律**。

# 降落阶段全景安全防御体系（Landing Defense System）

降落是起飞的镜像，但难度更高：起飞的地空转换由飞手/程序主动发起（时机确定），而**着陆的触地时机本质上不可精确预知**——防御体系必须"提前预置、被动兜住"。

```
 水平进场对准        垂直下降           触地瞬间           确认与停机
     │                 │                 │                  │
     ▼                 ▼                 ▼                  ▼
┌──────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│防线1     │   │防线2 mix预置  │   │防线6 物理铁闸 │   │防线7 1s检测  │
│分段状态机 │   │防线3 两段限速 │   │(0ms 生效)    │   │  与软停机    │
│mix=0.5   │   │防线8 大扰逃生 │   │防线4 位置软化 │   └──────────────┘
└──────────┘   └──────────────┘   │防线5 风向标解耦│
                                  └──────────────┘
```

## 防线 1【水平进场与垂直下降的分阶段精细状态机（Multi-stage Descent State Machine）】

**目标**：按空间位置与动作意图精准划分控制优先级——"降落"不是一个状态，是一串状态。

**实现机理**：ArduPilot QuadPlane 将自动着陆拆为精细阶段（`QPOS_APPROACH → AIRBRAKE → POSITION1 → POSITION2 → LAND_DESCEND → LAND_FINAL → LAND_COMPLETE`），并在 `update_throttle_mix()` 中按阶段分配权限：

```cpp
/* special case for auto landing, we want a high degree of
   attitude control until LAND_FINAL */
if (in_vtol_land_sequence()) {
    use_mix_max = !in_vtol_land_descent() || poscontrol.get_state() == QPOS_LAND_ABORT;
}
```

- **进场平移阶段**（`APPROACH`/`POSITION1/2`）：飞机在高位做减速、转弯、对准降落点的大机动，$mix = max$，姿态与位置控制权限拉满；
- **垂直下降阶段**（`LAND_DESCEND`/`LAND_FINAL` 及 QLAND 模式）：$mix = min$，优先保证垂直穿透与稳定下降（原因见防线 2）；
- **着陆中止**（`LAND_ABORT`）：瞬间切回 $mix = max$，全权限爬升逃离。

**工程效果**：每个阶段的控制权限与该阶段的物理任务精确匹配，不存在"一套权限打全场"的粗糙妥协。

## 防线 2【高空下降段 mix=0.1 预置——穿透下洗涡环与油门暴冲抑制】

**目标**：解决"收油门到底依然降不下来"（痛点 P5，Ballooning）这一行业经典难题。

**物理机理**：多旋翼垂直下降时，桨盘自上而下穿行在**自己刚刚吹出去的下洗紊流（涡环区边缘）**中，桨盘进气必然不均，机身必然发生 $\pm2^\circ\sim5^\circ$ 的高频颠簸——这是气动本质，加大姿态功率不能消除。

**灾难推演（若下降段给 $mix=0.5$）**：设 $hover=0.40$，高度环要求下降，输出油门 $0.15$：

$$avg\_max = 0.15 \times 0.5 + 0.40 \times 0.5 = 0.275$$

紊流颠簸令姿态环持续索要差速 → 混控器持续把平均油门顶到 $avg\_max = 0.275 \approx hover$ 附近 → **飞机悬浮在紊流层里降不下去**，电机疯狂抽搐耗电，越悬停紊流越强，恶性循环。ArduPilot 官方注释一针见血：

> *"Rapid descent on quadplanes often leads to very poor attitude control and putting more power into attitude doesn't tend to fix it, **what we need to do is slow the descent**."*

**防线动作**：垂直下降段全程 $mix = 0.1$：$avg\_max = 0.15 \times 0.9 + 0.40 \times 0.1 = 0.175$，平均油门被死死压住，飞机带着轻微可接受的姿态波动**干脆利落地穿透紊流层**。姿态角速率环仍以满频率运行，在差速（非抬升）空间内正常镇定姿态。

**工程效果**：下降率忠实跟随指令；"收油门降不下来/降落像踩棉花"的现象根除。

## 防线 3【两段式下降限速（Two-stage Descent Speed Limiting）】

**目标**：兼顾下降效率与接地轻柔——从**源头削减接地动能**。

**实现机理**：
- **高空段**（`LAND_DESCEND`）：以较大下降率（$1.5\sim3.0\ \text{m/s}$，如 `Q_LAND_SPEED_DN` / `LAND_ALT_LOW` 以上）快速下降，节省时间与电量；
- **低空段**（进入 `LAND_FINAL` 高度阈值，典型 10m）：切换为轻触速度 `LAND_SPEED`（典型 $0.3\sim0.7\ \text{m/s}$）恒速沉降，直至触地。

**能量账**：接地冲击能量 $E = \frac{1}{2}mv^2$ 与速度平方成正比。从 $2.0\ \text{m/s}$ 降到 $0.5\ \text{m/s}$，冲击能量缩小 **16 倍**——起落架载荷、触地角速度冲击、弹跳能量全部从源头上被削减一个数量级。

**工程效果**：与防线 6（铁闸）形成"源头减能 + 末端封锁"的组合拳：前者让冲击本身变小，后者保证残余冲击不被放大。

## 防线 4【水平位置控制器接地软化（Loiter Softening / Horizontal Release on Landing）】

**目标**：杜绝接地瞬间水平位置环死咬 GPS 坐标导致的"原地绊倒"（痛点 P4）。

**灾难场景**：飞机触地时 GPS 显示水平偏差 0.4m（漂移或风飘）。位置环忠实地索要 $8^\circ$ 倾角去"飞回"目标点——但起落架已被地面摩擦力别住，倾角指令变成了纯粹的推倒自己的力矩，飞机以起落架为支点侧翻。

**实现机理**：进入降落末段与触地检测生效时，执行 `loiter_soften_for_landing()`：将水平位置目标实时重置为当前位置、倾角需求深度软化趋零——**位置环从"死咬坐标"切换为"跟随现实"**（与防线 3【姿态释放】异曲同工，一个管姿态、一个管位置）。

**工程效果**：飞机垂直沉降接地，起落架不受横向扭擦，无侧翻。

## 防线 5【风向标偏航力矩接地解耦（Weathervane Deactivation on Touchdown）】

**目标**：防止垂起固定翼触地后风向标（Weathervane）控制器继续强行扭机头。

**灾难场景**：垂起固定翼在侧风中降落，风向标控制器持续输出偏航力矩令机头对风。触地后机轮/起落架与地面摩擦锁死，偏航力矩变成翻滚力矩，扭翻机身。

**实现机理**：触地检测（`should_relax()`）生效时风向标输出直接归零；同时该逻辑在地面速度过大时也保持静默，避免与滑跑冲突。

**工程效果**：接地后偏航轴完全平静，起落架不承受侧向扭转负荷。

## 防线 6【触地前瞻预置 vs 零毫秒物理铁闸——根除着陆弹跳】

**目标**：彻底杜绝起落架撞击地面瞬间的剧烈弹跳与侧翻（痛点 P6）——本防线是全体系中对"时序不可预知"问题的最优雅解答。

**核心思想——前瞻预置（Pre-set）**：触地时机不可精确预知，触地检测又需要时间（见防线 7），因此**任何"检测到触地再反应"的方案都注定来不及**。解法是把防御措施在还在空中时就预置到位：

```
t = -5.0 s : 进入垂直下降段 → mix 已在空中滑至 0.1（防线 1/2 顺带完成了预置！）
t =  0 ms  : 起落架撞地瞬停，角加速度（dω/dt）剧烈脉冲飙升
             → 姿态角速率 D 环在 2ms 内算出巨大纠偏力矩（想暴拉对角电机）
             → 【mix=0.1 铁闸早已在岗】推力上限锁死 0.05，力矩指令物理上无法兑现
             → 飞机像被吸盘吸住一样稳稳贴地，零弹跳
t = 0~1000 ms : 着陆检测计时器累积确认（防线 7）
t = 1000 ms   : 确认着陆 → relax 控制器 → 自动上锁停机
```

**关键洞察**：防线 2 为"穿透紊流"设置的 $mix=0.1$，恰好同时就是触地防弹跳所需的预置状态——**一个机制在时间轴上串起两个防御目标**，这是该设计被 ArduPilot 沿用十年的根本原因。防跳与防紊流不是两个功能，是同一条物理原理（限制平均推力抬升权）在不同时刻的两次兑现。

**工程效果**：接地零弹跳；触地瞬间的 D 环暴冲被物理级封杀，不依赖任何检测延迟。

## 防线 7【接地检测双重判定与延时停机（1.0s Landing Detector & Soft Disarm）】

**目标**：防止空中误判着陆导致"空中上锁自由落体"（痛点 P7），并在真实触地后平稳关停动力。

**实现机理**：ArduCopter 的着陆检测器（`update_land_detector()`，源码注释明确列出了**不可用**的传感器：气压计受地效干扰、EKF 垂直速度受触地冲击污染、姿态角受地面不平影响……）采用的判据组合是：

```cpp
// check that the average throttle output is near minimum
bool motor_at_lower_limit = motors->limit.throttle_lower;
bool throttle_mix_at_min  = attitude_control->is_throttle_mix_min();
// + 垂直速度接近零 + 加速度平稳，持续 LAND_DETECTOR_TRIGGER_SEC (1.0s)
```

- **油门顶到下限**（`limit.throttle_lower`）：高度环已经把油门压到底还嫌高——只有坐在地上才会这样；
- **mix 已处于最小**（`is_throttle_mix_min()`）：确认混控器不是因为姿态借力才碰到下限；
- **运动静止**：垂直速度≈0、加速度滤波值平稳；
- **持续 1.0 秒**全部满足，才置 `land_complete = true`，随后 relax 控制器、按条件自动上锁。

**为什么必须 1.0 秒**：强下沉气流中飞机可能瞬时出现"低油门+低速度"的空中假象，瞬时判定会导致空中停机坠毁。1 秒滤波确认是"漏判（晚 1 秒停机，无害）"与"误判（空中停机，机毁）"之间的必然取舍——**宁可慢确认，绝不错杀**。

**工程效果**：与防线 6 分工明确——铁闸管 0ms 的物理安全，检测器管 1s 的流程确认，各司其职互不依赖。

## 防线 8【下降段突发大扰动越级逃生（Large Disturbance Escape）】

**目标**：$mix=0.1$ 的下降过程中遭遇极端气流时的翻扣兜底（起飞防线 10 的降落镜像）。

**实现机理**：下降段每拍监测推力角误差，一旦被切变风吹破 $30^\circ$，`large_angle_error` 触发，1 拍内强制 $mix = max$，姿态环获得全部行程全力改平；误差收敛回阈值内后再按慢速斜坡（$0.5/\text{s}$）退回低权限状态。

**工程效果**：柔顺接地与极端抗扰两不误；权限的收与放全部由明确物理量（推力角误差）触发，行为可预期、可复盘。

# 传感器与状态估计层的起落专项防护（EKF & Sensor Protection）

控制层的所有防线都建立在"状态估计正确"之上。而起降区恰恰是传感器最容易说谎的地方。

## 气压计地效正压陷阱与补偿（Ground Effect Baro Anomaly Compensation）

**物理现象**：离地/接地 $0.5\sim1.0\ \text{m}$ 区间，桨盘下洗气流撞击地面反弹，在机壳气压计进气孔处形成**局部高压区**。气压升高在气压高度计上等价于"高度降低"——飞控误以为飞机正在下沉（误差可达数米，ArduPilot 源码注释：*"ground effect can cause errors larger than 4m"*）。

**灾难链条**：气压虚报下沉 → 高度环拉大油门补偿 → 起飞时暴冲上蹿 / 降落时拒绝接地、触地又弹起。

**防御算法**：
- **EKF 地效补偿模型**：飞控在起降阶段向 EKF 显式声明"预期地效"（ArduPilot EKF3 的 takeoff expected / touchdown expected 标志与 `EK3_GND_EFF_DZ` 气压死区参数），在地效窗口内动态下调气压计观测权重、放大垂直通道量测噪声——让 EKF 在这段时间"多信加速度计积分、少信气压计"；
- **多源高度融合**：测距仪（超声波/激光雷达）在低空对地高度上权重升高，与气压计加权互补；
- **着陆检测主动避开气压计**（见 3.7 源码注释）：着陆判据完全不使用气压高度与 EKF 垂直速度，从根上免疫地效污染。

## 垂直通道加速度计与陀螺仪抗震滤波

- **触地冲击频谱**：起落冲击是宽频瞬态，与电机震动（窄带谐波）不同。IMU 前级抗混叠滤波 + 动态陷波滤波器（Notch Filter，跟踪电机转速）分频治理；
- **EKF 创新度门限（Innovation Gate）**：触地瞬间加速度计短时饱和/削顶（clipping）时，超限观测被门限拒绝，防止单帧坏数据击穿高度与速度估计；
- **多 IMU 表决**：不同减震等级的 IMU 在冲击下表现不同，EKF lane 切换机制自动选用最健康的一组。

# 终极失效兜底：物理颠覆紧急熔断（Crash Check & Emergency Motor Cutoff）

当以上所有防线全部失效、飞机已经物理翻覆时，最后的问题不再是"怎么救飞机"，而是"怎么不引发次生灾害"。

**实现机理**（ArduCopter `crash_check()`，逐条件精确引用）：

```cpp
#define CRASH_CHECK_TRIGGER_SEC         2       // 持续 2 秒判定坠机
#define CRASH_CHECK_ANGLE_DEVIATION_DEG 30.0f   // 姿态误差超 30° 视为失控
#define CRASH_CHECK_ANGLE_MIN_DEG       15.0f   // 机身至少倾斜 15°
#define CRASH_CHECK_SPEED_MAX           10.0f   // 速度低于 10m/s（排除高速飞行工况）
#define CRASH_CHECK_ACCEL_MAX           3.0f    // 加速度低于 3m/s²（已趴住不动）
...
if (crash_counter >= (CRASH_CHECK_TRIGGER_SEC * scheduler.get_loop_rate_hz())) {
    gcs().send_text(MAV_SEVERITY_EMERGENCY, "Crash: Disarming ...");
    copter.arming.disarm(AP_Arming::Method::CRASH);   // 越过一切控制器，直接断电
}
```

判定逻辑的严谨性值得学习：**姿态误差大（失控）+ 机身倾斜（不是正常机动）+ 速度低（不是在飞）+ 加速度小（已经趴住）+ 持续 2 秒（不是瞬态）**——五个条件同时满足才熔断，任何一个不满足立即清零计数器。宁可熔断慢，绝不误杀飞行中的飞机。

**保护对象**：熔断保护的不是飞机（它已经翻了），而是：
- 电机堵转烧毁与电调过流起火（锂电池火灾）；
- 螺旋桨打地碎片飞溅造成**人身伤害**；
- 拖着全速旋转的桨在地面"跳舞"造成的二次损毁。

同类机制还包括：**推力丢失检测**（`thrust_loss_check()`：水平姿态+满油门+持续掉高 1 秒 → 判定单电机失效，启动 thrust boost 应急救机）与飞手**紧急停机开关**（Motor Emergency Stop / PX4 Kill Switch）——后者把最终否决权交还给人。

# 纵深防御控制哲学与跨层协同机制（Engineering Philosophy）

## 软件算法意图管理（上层） vs 硬件物理边界铁闸（底层）

回顾全部 19 道防线，会发现它们严格遵守同一分工：

| 层 | 典型防线 | 管什么 | 允许失效吗 |
|---|---|---|---|
| 意图层 | 姿态释放、I 环冻结、位置软化、着陆检测 | 让控制器**不想**输出危险指令 | 允许（有下层兜底） |
| 物理层 | mix 铁闸、Spool 状态机、限速 | 让危险指令**无法**兑现为推力 | 允许（有熔断兜底） |
| 熔断层 | Crash Check、紧急停机 | 灾难既成后**不扩大**损失 | 不允许 |

上层追求"聪明"（理解意图、平滑体验），底层追求"愚蠢的可靠"（无条件封锁、毫秒级生效）。**聪明的模块允许犯错，正是因为愚蠢的模块从不犯错。**

## 非对称安全法则（Asymmetric Safety Law）在起降中的映射

- **允许大油门向姿态让步**：空中饱和时宁可短暂掉高（可自愈——姿态改平油门即恢复）也要保姿态；
- **严禁小油门向姿态妥协**：地面/下降段绝不允许姿态借口抬升平均推力（不可自愈——地面暴冲、拒绝下降、触地弹跳都是发散性事故）。

一句话：**下坠是良性瞬态，上蹿是失控发散**——所有 mix 相关防线的方向性设计都源于这一条物理判断。

## 时间维度的不对称设计（Temporal Asymmetry）

- **mix 权限斜坡"快升慢降"**（$2.0/\text{s}$ 上升 vs $0.5/\text{s}$ 下降）：给权限要快（离地瞬间必须满血抗风），收权限要稳（防止空中权限骤失引发姿态跳变）；
- **着陆检测"慢进快出"**：判着陆需 1.0 秒持续滤波确认（防空中误判停机），判起飞瞬时生效（油门一推立即清除着陆标志）；
- **熔断判定"慢触发"**：Crash Check 要求持续 2 秒（绝不误杀还在挣扎自救的飞机）。

三处时间常数的方向选择都指向同一原则：**向危险方向的状态转移要慢要谨慎，向安全方向的状态转移要快要果断。**

## 经典开源飞控实现对照（ArduPilot vs PX4）

| 机制 | ArduPilot | PX4 |
|---|---|---|
| 权限仲裁 | `update_throttle_mix()` + `_throttle_rpy_mix` 斜坡 | 混控器 airmode 与 thrust 分配策略 |
| 着陆检测 | `update_land_detector()` 单级 1.0s 判定（油门下限 + mix min + 静止） | `LandDetector` 三级状态机：`ground_contact(0.35s) → maybe_landed(0.25s) → landed(0.3s)`，逐级收紧控制权限 |
| 地效补偿 | EKF3 takeoff/touchdown expected + `EK3_GND_EFF_DZ` | ECL EKF 同类地效抑制逻辑 |
| 紧急熔断 | `crash_check()` 自动判定 + Motor EStop | Kill Switch（飞手全权）+ attitude failure 检测 |
| 设计取向 | 自动判定为主，阈值保守 | 分级渐进 + 飞手最终否决权 |

两家实现细节不同，但**分层纵深、前瞻预置、时间不对称**三大原则完全一致——这是两个独立演化了十几年的全球机队用炸机数据共同收敛出的工程真理。

# 总结：起落安全的十条军规

1. **飞行中的任何抢救，都不如地面上的一次拒绝**——解锁检查是拦截率最高的防线。
2. **解锁 ≠ 起飞**——起飞意图必须由飞手显式表达，解锁动作本身必须绝对安全。
3. **地面不平不是姿态误差**——期望对齐实际（Relax），P 环无差可纠。
4. **地面上的积分是纯粹的翻转弹药**——未离地，I 环必须清零；慢推油门翻车的元凶从来不是 P 环。
5. **权限恢复必须跑在离地之前**——mix 斜坡 200ms 对电机升速 300ms，时间尺度错位是免费的安全裕度。
6. **慢腾腾的起飞不是温柔是危险**——果断穿出地效紊流层。
7. **下降段的敌人是自己的下洗气流**——限制平均推力抬升权，稳步穿透而非加力对抗。
8. **触地时机不可预知，所以防御必须前瞻预置**——mix=0.1 在空中就位，0ms 生效的物理铁闸胜过一切事后检测。
9. **向危险方向慢转移，向安全方向快转移**——快升慢降、慢进快出、慢熔断。
10. **每一层都假设其它层会失败**——意图层、物理层、熔断层各自独立成立，纵深防御的本质是对自己代码的不信任。
