# 引言：一个令人困惑的参数现象

在开源自驾仪（如 ArduPilot、PX4 等）的姿态控制算法中，角速率内环通常采用标准的 **PID + FF（比例-积分-微分-前馈）** 控制结构：

$$
u(t) = \underbrace{K_p \cdot e_\omega(t)}_{\text{比例反馈}} + \underbrace{K_i \int e_\omega(t) \, dt}_{\text{积分反馈}} + \underbrace{K_d \cdot \frac{d e_\omega(t)}{dt}}_{\text{微分反馈}} + \underbrace{K_{ff} \cdot \omega_{\text{target}}(t)}_{\text{前馈通路}}
$$

其中 $e_\omega(t) = \omega_{\text{target}}(t) - \omega(t)$ 为角速率误差，$\omega_{\text{target}}$ 为外环给出的期望角速率，$u(t)$ 为输出给混控分配器的无量纲控制量（通常归一化在 $[-1, 1]$）。

初学飞控源码或调参时，控制工程师往往会发现一组看似矛盾的现象：

1. **常规多旋翼（Multirotor）**：滚转、俯仰、偏航三个轴的角速率前馈系数几乎**全部默认设为 0**（$K_{ff} = 0$）；
2. **常规固定翼（Fixed-Wing）**：副翼、升降舵的角速率前馈通常设为一个较大的正值（如 $0.2 \sim 0.5$）；
3. **双发尾座式垂直起降飞机（Dual-Rotor Tailsitter）**：在悬停模式下，**俯仰轴和偏航轴的前馈为 0.2 左右的正值，但滚转轴的前馈却依然严格保持为 0**；
4. **传统直升机（Helicopter）**：斜盘周期变距控制的滚转和俯仰轴，前馈不仅非零，而且是系统的主力控制项。

为什么同为角速率跟踪，不同机型甚至同一架飞机的不同轴向，对前馈的需求会有本质区别？如果把多旋翼的前馈强行调大，飞机究竟会发生什么？本文从第一性原理和频域建模出发，剖析角速率前馈的物理本质。

# 物理与数学建模：为什么两种机型的角速率环规律完全相反？

控制律的结构完全取决于被控对象的物理模型。我们分别对纯多旋翼与翼面控制建立动力学方程。

```text
【纯多旋翼模式 (无阻尼刚体)】
  控制量 u ──► 电机差动力矩 M ──► 产生角加速度 α = M/I ──► 积分得到角速度 ω
  结论：维持定常角速度 (dω/dt = 0) 所需力矩为 0！

【翼面 / 尾座式模式 (强阻尼系统)】
  控制量 u ──► 舵面偏角 δ ──► 产生控制力矩 M_δ · δ
                              与气流旋转阻尼力矩 -M_q · ω 对抗
  结论：维持定常角速度 (dω/dt = 0) 必须持续打舵平衡阻尼！
```

## 纯多旋翼（悬停刚体）：纯积分系统与角加速度控制

在悬停或低速飞行状态下，多旋翼主要依靠对侧电机的转速差（差动推力）产生旋转力矩。此时机体绕自身质心旋转时受到的空气阻力极其微弱，在工程上可精确建模为**理想无阻尼刚体**：

$$
I \cdot \dot{\omega}(t) = M_{\text{motor}}(t) = K_m \cdot u(t)
$$

* $I$：机体绕该轴的转动惯量；
* $\dot{\omega}(t)$：机体角加速度；
* $K_m$：执行器控制增益（电机差动产生单位控制量对应的力矩）；
* $u(t)$：混控器给出的差动控制指令。

**关键物理结论**：
1. **控制量直接控制角加速度 $\dot{\omega}$，而不是角速度 $\omega$**；
2. **当多旋翼以恒定角速度 $\omega_{\text{target}}$ 旋转时，角加速度 $\dot{\omega} = 0$**。这意味着：**维持定常角速度所需的净力矩为 0**；
3. 如果此时在控制器中加入 $K_{ff} \cdot \omega_{\text{target}}$，当飞机达到目标角速度时控制器依然在持续输出推力矩，导致机体继续加速严重超调，PID 反馈回路被迫反向减速，引发前后打架与剧烈晃动。

因此，**纯多旋翼的角速率内环不能引入目标角速度作为力矩前馈，$K_{ff}$ 必须恒为 0**。

## 翼面/尾座式（滑流翼面）：一阶惯性系统与时域解析解

当飞机依靠翼面控制（如固定翼飞机平飞，或双发尾座式垂直起降飞机在悬停时舵面处于螺旋桨的高速滑流中）时，流场特性发生了根本改变。

当机体绕某一轴以角速度 $\omega$ 旋转时，机翼和尾翼在气流中切割空气，产生一个与旋转角速度大小成正比、方向相反的**气动阻尼力矩（Aerodynamic Damping Moment）**：

$$
M_{\text{damping}}(t) = - M_q \cdot \omega(t)
$$

其中 $M_q > 0$ 为气动阻尼导数（Damping Derivative）。

结合舵面偏转 $\delta(t)$ 产生的气动控制力矩 $M_\delta \cdot \delta(t)$，机体完整的单轴旋转动力学微分方程为：

$$
I \cdot \dot{\omega}(t) + M_q \cdot \omega(t) = M_\delta \cdot \delta(t)
$$

将上式两边同除以阻尼导数 $M_q$，可化为经典自动控制理论的标准一阶常微分方程：

$$
\tau \cdot \dot{\omega}(t) + \omega(t) = K_{\text{plant}} \cdot \delta(t)
$$

其中：
* **系统时间常数（惯性滞后时间）**：$\tau = \frac{I}{M_q}$（单位：$\text{s}$），表征机体旋转角速度在阻尼作用下衰减的快慢；
* **受控对象稳态增益（舵效与阻尼比）**：$K_{\text{plant}} = \frac{M_\delta}{M_q}$（单位：$(\text{rad/s}) / \text{rad}$ 或无量纲）。

**1、阶跃输入下的时域精确解析解**

设系统初始静止（$\omega(0) = 0$），在 $t=0$ 时刻舵面突加一个恒定偏角 $\delta(t) = \delta_0$。通过一阶微分方程积分求解，角速度的时域精确解析解为：

$$
\omega(t) = K_{\text{plant}} \cdot \delta_0 \left( 1 - e^{-\frac{t}{\tau}} \right) = \left( \frac{M_\delta}{M_q} \right) \cdot \delta_0 \left( 1 - e^{-\frac{M_q}{I} t} \right)
$$

**2、稳态平衡条件（$t \to \infty$ 或 $\dot{\omega} = 0$）**

当过渡过程结束、系统进入定常旋转状态时（$t \to \infty$），指数衰减项 $e^{-t/\tau} \to 0$，角加速度 $\dot{\omega} = 0$：

$$
\omega_{\text{steady}} = K_{\text{plant}} \cdot \delta_0 = \left( \frac{M_\delta}{M_q} \right) \cdot \delta_0
$$

反解维持目标角速度 $\omega_{\text{target}}$ 所必需的稳态舵偏角：

$$
\delta_{\text{steady}} = \frac{\omega_{\text{target}}}{K_{\text{plant}}} = \left( \frac{M_q}{M_\delta} \right) \cdot \omega_{\text{target}}
$$

**关键物理结论**：
> 在气流中，机体要想维持恒定的旋转角速度 $\omega_{\text{target}}$，**舵面必须持续打着一个固定角度 $\delta_{\text{steady}}$，以持续克服迎面而来的气动阻尼**。一旦舵面回中（$\delta = 0$），气动阻尼力矩会在瞬间将旋转角速度耗散归零。
> 
> **维持目标角速度所需的稳态舵偏，与目标角速度 $\omega_{\text{target}}$ 严格成正比！**

## 传递函数与直流增益：控制理论严格推导与直观物理画像

### 控制理论基础：拉普拉斯变换与终值定理（Final Value Theorem）

在经典控制理论中，假设系统初始条件为零，对时域微分方程进行拉普拉斯变换（$\mathcal{L}\{\dot{y}(t)\} = s Y(s)$），输入输出之比即为**传递函数（Transfer Function）** $G(s) = \frac{Y(s)}{U(s)}$。

根据拉普拉斯变换的**终值定理（Final Value Theorem）**，对于单位阶跃输入 $u(t) = 1(t) \Longleftrightarrow U(s) = \frac{1}{s}$，系统的稳态输出值 $y_{\text{ss}}$ 为：

$$
y_{\text{ss}} = \lim_{t \to \infty} y(t) = \lim_{s \to 0} s \cdot Y(s) = \lim_{s \to 0} \left[ s \cdot G(s) \cdot \frac{1}{s} \right] = \lim_{s \to 0} G(s)
$$

由此得出控制工程的核心定义：
$$
\text{系统开环直流增益 (DC Gain)} \equiv \lim_{s \to 0} G(s) = \frac{y_{\text{steady}}}{u_{\text{steady}}}
$$

* **直观本质**：“直流”（DC）在频域中代指频率为 0 的恒定稳态信号。**直流增益正是系统在稳态下的静态放大倍数**。

### 纯多旋翼模型：纯积分环节（Type-1 系统）

对多旋翼动力学方程 $I \dot{\omega}(t) = K_m u(t)$ 实施拉氏变换：

$$
I \cdot s \Omega(s) = K_m U(s) \implies G_{\text{multi}}(s) = \frac{\Omega(s)}{U(s)} = \frac{K_m / I}{s}
$$

* **严格数学性质**：坐标原点处存在一个极点（$s = 0$），属于典型的**一型系统（纯积分器）**；
* **直流增益计算**：
$$
\text{DC Gain}_{\text{multi}} = \lim_{s \to 0} G_{\text{multi}}(s) = \lim_{s \to 0} \frac{K_m / I}{s} = \infty
$$
* **前馈需求逆推**：
$$
u_{\text{steady}} = \frac{\omega_{\text{target}}}{\text{DC Gain}_{\text{multi}}} = \frac{\omega_{\text{target}}}{\infty} = 0
$$

【直观物理画像：真空中滑冰】

* **物理实验**：想象你在完全光滑的真空中推多旋翼，只要你给一个微小的恒定力矩指令（输入 $u = 1$），飞机就会以恒定加速度持续加速旋转，角速度 $\omega$ 会从 $10 \to 100 \to 1000 \, \text{rad/s}$ 无限飙升。
* **物理结论**：由于没有阻力消耗能量，多旋翼一旦加速到目标角速度，维持匀速旋转**所需要的净力矩为 0**。若此时在控制器前馈中注入 $K_{ff} \cdot \omega_{\text{target}}$，等于在达到目标车速后依然死踩油门不放，系统必然严重超调失控。

### 固定翼/尾座式翼面模型：一阶惯性环节（Type-0 系统）

对翼面旋转动力学方程 $I \dot{\omega}(t) + M_q \omega(t) = M_\delta \delta(t)$ 实施拉氏变换：

$$
(I s + M_q) \Omega(s) = M_\delta \Delta(s) \implies G_{\text{wing}}(s) = \frac{\Omega(s)}{\Delta(s)} = \frac{M_\delta / I}{s + \frac{M_q}{I}} = \frac{K_{\text{plant}}}{\tau s + 1}
$$

* **严格数学性质**：极点位于左半平面 $s = -\frac{M_q}{I} < 0$，属于典型的**零型一阶惯性系统**；
* **直流增益计算**：
$$
\text{DC Gain}_{\text{wing}} = \lim_{s \to 0} G_{\text{wing}}(s) = \lim_{s \to 0} \frac{K_{\text{plant}}}{\tau s + 1} = K_{\text{plant}} = \frac{M_\delta}{M_q} \quad (\text{有限非零常数})
$$
* **前馈需求逆推**：
$$
\delta_{\text{steady}} = \frac{\omega_{\text{target}}}{\text{DC Gain}_{\text{wing}}} = \frac{\omega_{\text{target}}}{M_\delta / M_q} = \left( \frac{M_q}{M_\delta} \right) \cdot \omega_{\text{target}}
$$

【直观物理画像：水底划船】

* **物理实验**：把舵面固定在某个偏角（输入 $\delta = 5^\circ$）。飞机旋转时在气流中切割空气产生阻尼，转速越快阻力越大。当阻力矩恰好增大到与舵面力矩完全相抵时，加速度归零，角速度稳定在一个有限常数（如 $50^\circ/\text{s}$）。
* **物理结论**：要想让机体在流体阻力中维持匀速旋转，**必须持续提供稳态舵偏以平衡阻尼**。所需稳态舵偏恰好等于目标角速度除以直流增益。

### 两种受控对象特性对比矩阵

| 特性维度 | 纯多旋翼（悬停刚体） | 翼面 / 尾座式（滑流翼面） |
|---|---|---|
| **动力学微分方程** | $I \dot{\omega}(t) = K_m u(t)$ | $I \dot{\omega}(t) + M_q \omega(t) = M_\delta \delta(t)$ |
| **开环传递函数 $G(s)$** | $\frac{K_m / I}{s}$（纯积分环节） | $\frac{M_\delta / M_q}{\frac{I}{M_q}s + 1}$（一阶惯性环节） |
| **系统分类** | Type-1 系统（极点在原点 $s=0$） | Type-0 系统（极点在 $s = -M_q/I$） |
| **开环直流增益 (DC Gain)** | $\infty$（无界） | $\frac{M_\delta}{M_q}$（有限常数） |
| **阶跃输入稳态响应** | 角速度无限积分发散 | 达到有限稳态角速度 $\omega_{\text{steady}}$ |
| **定常旋转所需稳态输入** | $u_{\text{steady}} = 0$ | $\delta_{\text{steady}} = \left(\frac{M_q}{M_\delta}\right) \omega_{\text{target}}$ |
| **角速率动力学前馈 $K_{ff}$** | **严格为 0** | **必须为正值（$\approx \frac{M_q}{M_\delta}$）** |

# 前馈增益 $K_{ff}$ 的物理本质：逆模型增益 $M_q / M_\delta$

## 理论推导：全频域逆模型与稳态前馈 $K_{ff} = 1/\text{DC\_Gain}$

在现代控制理论的二自由度（2-DOF）控制结构中，**前馈控制器（Feedforward Controller）的最优解析解即为受控对象的逆动力学模型（Inverse Plant Model）**：

$$
C_{ff}(s) = G^{-1}(s)
$$

将一阶翼面受控对象传递函数 $G_{\text{wing}}(s) = \frac{M_\delta / I}{s + \frac{M_q}{I}} = \frac{K_{\text{plant}}}{\tau s + 1}$ 代入逆模型展开：

$$
C_{ff}(s) = \frac{\tau s + 1}{K_{\text{plant}}} = \underbrace{\frac{M_q}{M_\delta}}_{\text{零阶稳态前馈 } K_{ff}} + \underbrace{\left( \frac{I}{M_\delta} \right) \cdot s}_{\text{一阶微分前馈 } K_{d\_ff}}
$$

对该全频域前馈逆模型进行严格数学解构：

1. **稳态前馈项（常数项，对应 $s \to 0$）**：
   $$
   K_{ff} \equiv \lim_{s \to 0} C_{ff}(s) = \frac{1}{\text{DC Gain}_{\text{wing}}} = \frac{M_q}{M_\delta}
   $$
   * **物理职责**：开环提供克服**气动旋转阻尼力矩**所需的稳态偏转舵角；
2. **动态前馈项（微分项，对应 $s$）**：
   $$
   K_{d\_ff} = \frac{I}{M_\delta}
   $$
   * **物理职责**：在指令快速突变时，开环提供克服**机体转动惯量**所需的瞬态角加速度脉冲力矩（$M = I \cdot \dot{\omega}^*$）。这正是第 4.3 节所述的高阶角加速度前馈项（Target Derivative FF）的理论数学源头。

```text
             ┌───────────────────────────────────────┐
             │ 理想逆模型前馈通道: C_ff(s) = G^-1(s)    │
             │  • 稳态前馈: u_ff  = (Mq/Mδ) · ω*      │
ω_target ───►│  • 惯性前馈: u_dff = (I/Mδ) · dω*/dt   ├──► u_FF ──┐
             └───────────────────────────────────────┘           │
                                                                 ▼
                   ┌──────────────────────────────┐            ┌───┐   执行器指令 u   ┌───────────────────────┐
ω_target ──►(+)───►│          PID 反馈             ├────► u_FB─►│ + ├───────────────►│ 真实飞机 (一阶惯性系统)   ├──► 实际角速度 ω
             ▲ -   └──────────────────────────────┘            └───┘                 │ G(s) = (Mδ/I)/(s+Mq/I)│
             │                                                                       └───────────┬───────────┘
             └───────────────────────────────────────────────────────────────────────────────────┘
```

由此得出贯通飞行力学与自动控制理论的数学定论：
$$
K_{ff} \equiv \frac{1}{\text{DC Gain}} = \frac{M_q}{M_\delta}
$$

* **纯多旋翼**：$\text{DC Gain} = \infty \implies K_{ff} = \frac{1}{\infty} = 0$；
* **固定翼/尾座式翼面**：$\text{DC Gain} = \frac{M_\delta}{M_q} \implies K_{ff} = \frac{M_q}{M_\delta} > 0$（通常为 0.2~0.5 之间）。

## 频域相位分析：为什么前馈通道具备“零相位滞后”优势？

从控制系统的频域波特图（Bode Plot）与时域响应机理分析：

* **传统 PID 反馈回路的本质缺陷（相位滞后）**：
  PID 必须等到实际角速度 $\omega$ 与期望值 $\omega_{\text{target}}$ 产生误差（Error）后才能计算输出。受控对象一阶惯性环节自身具备相位滞后 $\phi(\Omega) = -\arctan(\Omega \cdot \tau)$，加上传感器采样滤波与执行器响应延迟，反馈回路不可避免地存在**显著的时间相位滞后（Phase Lag）**；
* **前馈通道的巨大优势（零相位滞后）**：
  前馈通道直接获取操纵手的期望角速率指令 $\omega_{\text{target}}$，通过逆模型在**打杆的同一计算拍（$t = 0$ 时刻）直接算出所需的主力舵偏（通常占总需求输出的 80%~90%）**。
  输出舵量不经由误差积分累积，直接跳过反馈环路的延迟链条，**在开环意义上实现零相位滞后的极速响应**；
* **反馈环路（PID）的重新定位**：
  引入前馈后，PID 不再需要承担打满舵的主力输出职责，退居为“纠偏修边角”的辅助角色——仅负责抑制风扰、电池压降、气动非线性等残差。这使得控制工程师可以将 PID 增益调得更加柔和温和，彻底避免了高反馈增益引发的系统高频振荡与机体颤抖。

## 气动阻尼微观来源：旋转诱导迎角

为什么机翼切割空气会产生与旋转速率成正比的阻尼力矩？从翼剖面的微观流场分析：

```text
          机体绕重心以俯仰角速度 q 旋转 (抬头)
                     ↺ q
              ▲                   │
              │ 尾翼向上运动        │ 主机翼向下运动
              │ V_tail = q · l_t  │
              ▼                   ▼
      ───────► 迎面来流 V_inf
         \ 气流相对斜向吹来
          \
           ▼ 局部相对迎角减小 (Δα < 0) ──► 尾翼升力减小 (产生向下反作用力矩)
```

以飞机抬头（俯仰角速度 $q > 0$）为例：
1. 位于机身后方的平尾以速度 $v = q \cdot l_t$ 向上运动（$l_t$ 为尾翼力臂）；
2. 迎面来流 $V_{\infty}$ 与向上运动速度合成，使尾翼感受到的有效相对气流方向向下偏转，产生了**负的诱导附加迎角** $\Delta \alpha_t \approx -\frac{q \cdot l_t}{V_{\infty}}$；
3. 迎角减小导致尾翼升力瞬时下降，产生一个**低头力矩**，阻碍机体抬头。

阻尼力矩表达式为：
$$
M_{\text{damping}} = \frac{1}{2} \rho V_{\infty}^2 S \bar{c} \cdot C_{m_q} \cdot \left( \frac{q \bar{c}}{2 V_{\infty}} \right) \propto V_{\infty} \cdot q
$$
这在气动物理上严格证明了阻尼力矩与旋转角速率的一阶线性正比关系。

## 进阶机理：空速变化对 $K_{ff}$ 与 PID 的不同影响（$1/V$ 与 $1/V^2$ 的辨析）

在固定翼平飞过程中，飞行空速 $V_{\infty}$ 会在大范围内动态变化。许多初学者常有一个直觉误区：*“既然动压正比于 $V^2$，飞控的所有增益不都应该按 $1/V^2$ 缩放吗？”*

答案是：**PID 反馈增益按 $1/V^2$ 缩放，但 FF 前馈增益严格按 $1/V$ 缩放**。其气动与控制原理截然不同：

**1、PID 反馈项（P / I / D）：为什么按 $1/V^2$ 缩放？**

* **控制目标**：维持闭环控制回路的刚度（带宽）和阻尼比恒定；
* **物理机理**：舵面偏角产生控制力矩 $M_\delta \propto \frac{1}{2}\rho V_{\infty}^2$，受控对象从舵偏到角加速度的控制效能直接正比于动压（$V_{\infty}^2$）；
* **结论**：若空速增大 2 倍，气动力矩放大 4 倍；为了避免高速时系统因回路增益过大引发剧烈高频震颤，**PID 反馈增益必须按动压倒数 $1/V_{\infty}^2$ 进行缩放**。

**2、FF 前馈项：为什么严格按 $1/V$ 缩放？**

* **控制目标**：抵消定常旋转时的气动阻尼力矩，实现稳态逆模型开环平衡；
* **物理机理**：
  * **舵面控制力矩（分母）**：正比于动压（空速平方），$M_\delta = \frac{1}{2} \rho V_{\infty}^2 S \bar{c} \cdot C_{m_\delta} \propto V_{\infty}^2$；
  * **气动阻尼力矩（分子）**：正比于旋转诱导迎角与动压的乘积。因为诱导迎角 $\Delta \alpha = -\frac{q \cdot l}{V_{\infty}} \propto \frac{1}{V_{\infty}}$，乘上动压 $V_{\infty}^2$ 后，净阻尼力矩仅与空速一次方成正比：$M_q \propto V_{\infty}$；
* **前馈增益理论值**：
$$
K_{ff}(V) = \frac{M_q(V)}{M_\delta(V)} \propto \frac{V_{\infty}}{V_{\infty}^2} = \frac{1}{V_{\infty}}
$$
* **结论**：**前馈增益只需要按空速一次方 $1/V_{\infty}$ 进行缩放，而不是 $1/V_{\infty}^2$**。

**3、开源飞控工业实证（ArduPilot 源码）**

在 ArduPilot 开源飞控固定翼角速率控制器（`AP_FW_Controller.cpp`）中，可以清晰看到这一经典实现：
```cpp
// scaler = scaling_speed / airspeed，即 scaler ∝ 1/V
// 1. PID 反馈项输入乘以 scaler * scaler (按 1/V^2 缩放)
rate_pid.update_all(target * scaler * scaler, actual * scaler * scaler, dt, limit_I);

// 2. FF 前馈项除以 scaler (将平方还原为 1/V 缩放)
const float ff = degrees(rate_pid.get_ff_component() / (scaler * eas2tas));
```

* **尾座式悬停特例**：在尾座式 VTOL 悬停模式下，舵面感受到的气流主要来自螺旋桨的定常滑流（$V_{\text{slipstream}} \approx \sqrt{\frac{2T}{\rho A}}$），在恒定悬停油门下流速基本恒定，因此悬停模式下的 $K_{ff}$ 可以配置为一个固定常数（约 0.2）。

|---|---|---|---|
| **$K_{ff}$ 偏小（或为 0）** | 前馈舵量不足，产生持续正误差；必须依赖 I 项（积分）长时间累积才能顶住阻尼；松杆瞬间 I 项舵量无法立即消散。 | 响应慢，有明显相位滞后；松杆刹车时有小幅回弹过冲（Bounce-back）。 | 感觉飞机**“很肉”、“不跟手”、“黏糊糊”**。 |

# 辨析：飞控串级控制中不同层级「前馈」的区别

在飞控算法架构中，“前馈”出现在不同控制回路中，必须严格区分其物理量纲与数学定义。

```text
                 【外环：角度环】                              【内环：角速率环】
        ┌───────────────────────────────┐             ┌──────────────────────────────┐
        │ 运动学前馈: ω_ff = dθ*/dt       │             │ 动力学前馈: u_ff = K_ff · ω*  │
        └───────────────┬───────────────┘             └──────────────┬───────────────┘
                        │ (rad/s)                                    │ (归一化输出)
                        ▼                                            ▼
目标角度 ──►(+)──►[ 角度 P 环 ]──►(+)──► 目标角速度 ω* ──►(+)──►[ 角速率 PID ]──►(+)──► 执行器指令 u
 θ*         ▲ -                   ▲                 ▲ -                   ▲
            │                     │                 │                     │
测量角度 θ ──┴─────────────────────┘    测量角速率 ω ──┴─────────────────────┘
```

## 外环（角度环）运动学前馈：$\dot{\theta}^*$

* **作用位置**：由期望姿态角 $\theta^*$ 计算期望角速率 $\omega^*$ 的过程；
* **物理含义**：**运动学微分**（角度对时间的导数即为角速度）。当操作手快速推杆改变目标角度时，目标角度本身随时间变化率 $\dot{\theta}^* \neq 0$，这一运动速率被直接注入到内环目标中；
* **量纲关系**：量纲为 $\text{rad/s}$，直接与外环 P 控制器的输出（也是 $\text{rad/s}$）相加。多旋翼与固定翼均通用开启。

## 内环（角速率环）动力学前馈：$K_{ff} \cdot \omega^*$

* **作用位置**：由期望角速率 $\omega^*$ 计算执行器力矩/舵偏指令 $u$ 的过程；
* **物理含义**：**被控对象动力学逆模型**的气动阻尼力矩补偿；
* **适用对象**：**仅适用于强气动阻尼的翼面控制**（固定翼、直升机、尾座式 VTOL 的滑流舵面）。纯多旋翼恒为 0。

## 高阶角加速度前馈：$K_{d\_ff} \cdot \dot{\omega}^*$

* **物理含义**：机体转动惯量补偿（$M_{\text{inertia}} = I \cdot \dot{\omega}^*$）；
* **适用对象**：在高速特技穿越机或大惯量固定翼做剧烈机动时，对目标角速率微分得到目标角加速度，直接在前馈通道注入克服惯性加速所需的脉冲力矩（如部分现代飞控中的 Target Derivative FF）。

## 常见误区：为什么不能用 $\text{Error} / \Delta t$ 充当前馈？

控制工程初学者常有疑问：*“既然前馈反映动态趋势，能否将误差变化率 $\frac{e_\omega}{\Delta t}$ 作为前馈？”*

这在控制理论上存在两大致命概念错误：
1. **违背前馈定义**：前馈（Feedforward）是**纯粹基于参考输入（Target）的开环预测通路，严禁引入测量反馈误差（Error）**。一旦包含反馈量，其性质即变为反馈控制器；
2. **与微分项（D）完全重叠**：$\frac{e_\omega}{\Delta t}$ 正是标准离散 PID 控制器中的 **D（微分控制项）**。若在前馈通道重复引入，等效于将微分增益成倍放大，会剧烈放大陀螺仪高频噪声，导致电机发烫或舵机高频震颤烧毁。

# 典型飞行器构型的三轴前馈配置矩阵与物理机理

为什么双发尾座式（Dual-Rotor Tailsitter）在悬停时，各轴的前馈配置会呈现“偏航/俯仰开、滚转关”的特殊组合？答案完全取决于各轴执行机构的力学类型：

```text
       【双发尾座式 VTOL 悬停力学分配】

              ↑ 升力 (左电机)       ↑ 升力 (右电机)
             [ 旋翼 1 ]            [ 旋翼 2 ]
                 │                     │
                 │ 强螺旋桨滑流          │ 强螺旋桨滑流
                 ▼                     ▼
          ┌──────────────┐      ┌──────────────┐
          │  升降副翼 1   │      │  升降副翼 2    │
          └──────────────┘      └──────────────┘

  • 俯仰 (Pitch): 两侧升降舵同向偏转 ──► 气动阻尼主导 ──► [需开启 FF ≈ 0.2]
  • 偏航 (Yaw)  : 两侧副翼反向偏转   ──► 气动阻尼主导 ──► [需开启 FF ≈ 0.2]
  • 滚转 (Roll) : 左右电机差动推力   ──► 刚体惯性主导 ──► [保持 FF = 0]
```

|---|---|---|---|---|
| **常规四/六/八旋翼** | Roll / Pitch / Yaw | 电机差动推力；刚体惯性主导，气动阻尼近似为 0。 | **0.0** | 维持定常转速无需持续力矩；配置非零 FF 会导致严重超调。 |

| **传统直升机** | Roll / Pitch | 旋翼斜盘周期变距；旋翼挥舞阻尼（Flapping Damping）极大。 | **0.2 ~ 0.4** | 强一阶系统特性，前馈为最核心主力控制通道。 |
| **双发尾座式 VTOL (悬停)** | **Pitch（俯仰）** | 两侧升降舵同向偏转（处于螺旋桨高速滑流中）。 | **0.2** | 强气动阻尼主导，舵偏线性对应稳态俯仰角速率。 |
| | **Yaw（偏航）** | 两侧副翼差动偏转（处于螺旋桨高速滑流中）。 | **0.2** | 强气动阻尼主导，舵偏线性对应稳态偏航角速率。 |

# 标准算法实现架构（C++ 伪代码）

在工业级飞控实现中，角速率控制回路需要综合前馈计算、抗积分饱和（Anti-Windup）以及执行器限幅保护。以下为通用的标准实现参考：

```cpp
/**
 * @brief 姿态角速率 PID + 前馈控制器核心实现
 * @param rate_target_rads   外环期望体轴角速率 (rad/s)
 * @param rate_actual_rads   陀螺仪测量的实际角速率 (rad/s)
 * @param dt                 控制循环周期 (s)
 * @param is_actuator_sat    执行器是否已进入饱和状态 (由混控分配器反馈)
 * @return float             归一化执行器指令 [-1.0, 1.0]
 */
float Controller::update_rate_pid_ff(float rate_target_rads,
                                    float rate_actual_rads,
                                    float dt,
                                    bool is_actuator_sat)
{
    // 1. 计算角速率误差
    const float rate_error = rate_target_rads - rate_actual_rads;

    // 2. 比例项计算
    const float p_out = gain_p * rate_error;

    // 3. 微分项计算 (带一阶低通滤波)
    const float raw_derivative = (rate_error - last_rate_error) / dt;
    last_rate_error = rate_error;
    d_filter_state += d_lpf_alpha * (raw_derivative - d_filter_state);
    const float d_out = gain_d * d_filter_state;

    // 4. 前馈项计算 (基于动力学逆模型)
    // 对于纯多旋翼 gain_ff = 0; 对于固定翼/尾座舵面 gain_ff = Mq / Mdelta
    const float ff_out = gain_ff * rate_target_rads;

    // 5. 积分项更新 (带抗积分饱和与单向卸载逻辑)
    // 若执行器已饱和，仅允许误差方向能够减小积分绝对值时才更新积分
    const bool allow_integration = !is_actuator_sat || 
                                  ((integrator > 0.0f && rate_error < 0.0f) || 
                                   (integrator < 0.0f && rate_error > 0.0f));

    if (allow_integration && gain_i > 0.0f && dt > 0.0f) {
        integrator += gain_i * rate_error * dt;
        integrator = std::clamp(integrator, -integrator_max, integrator_max);
    }
    const float i_out = integrator;

    // 6. 控制量合成并施加执行器物理限幅
    const float total_output = p_out + i_out + d_out + ff_out;
    return std::clamp(total_output, -1.0f, 1.0f);
}
```

# 工程实战：角速率环 PID+FF 标准调参方法论

对于固定翼、尾座式等具有气动翼面的机型，应采用如下五步标准调参流程：

```text
步骤 1: 隔离闭环 (将 P 设为极小值, I 设为 0, D 设为 0)
         │
         ▼
步骤 2: 校准前馈 (做阶跃打杆, 逐步增大 FF, 直至实际角速率稳态值精准吻合目标值)
         │
         ▼
步骤 3: 引入比例 (增大 P 直至跟踪动态响应迅速, 消除起始爬升阶段的相位滞后)
         │
         ▼
步骤 4: 引入微分 (增大 D 抑制气流湍流抖动与超调尖峰)
         │
         ▼
步骤 5: 引入积分 (增大 I 消除安装偏差、重心偏置及风阻引起的微小静差)
```

**调参核心心法：**

> **“前馈定骨架，反馈修边角”**。
>
> 当且仅当前馈增益 $K_{ff}$ 准确反映受控对象的物理阻尼比时，在无风大机动飞行中，PID 的误差曲线才能够基本贴合零线。此时即使将积分增益 $I$ 设定得较为保守，飞行器依然能兼具极速无滞后的打杆响应与高稳定度的抗扰品质。

#  总结

1. **第一性原理**：力矩在真空中决定**角加速度**（纯积分系统），在强气动阻尼环境中决定**稳态角速度**（一阶惯性系统）；
2. **前馈的本质**：角速率动力学前馈 $K_{ff} \cdot \omega_{\text{target}}$ 本质是受控对象的**气动阻尼逆模型增益补偿**（$K_{ff} \approx \frac{M_q}{M_\delta}$）；
3. **构型法则**：
   * 纯多旋翼（差动推力控制）无气动阻尼，**前馈增益必须设为 0**；
   * 固定翼及尾座式舵面受滑流强阻尼主导，**必须设置合适的前馈增益（如 0.2~0.5）**，以实现零滞后开环响应并防止积分饱和。
4. **控制架构协同**：前馈负责高动态开环出力，反馈 PID 负责抗扰纠偏与模型自适应，二者各司其职是高性能飞行控制系统的核心精髓。
